# Development screen, 2026-10-19 (EMB-01 phase 1)

Every configuration ran through the service's own pack (router, arms, fusion `oa-rank-2`, signals,
diversification), on the same corpus and the same benchmarks. Metrics only. No texts, queries or
judgments are reproduced here.

## Setup

- **Corpus:** the Nigeria Data Protection Act, 2023 (an unreviewed machine reading), beside the
  synthetic laws: 4 works, 180 units, 170 of them with words to embed.
- **Benchmarks:**
  - `ng-legislation-dev-1`: 24 cases, 23 with relevant provisions and 1 unanswerable. The judgments
    are unreviewed, so this set is for development only.
  - `synthetic-smoke-1`: the CI gate set.
- **Engine:** Vespa 8.763.13, single node, in Docker. PostgreSQL 17 is the system of record and the
  comparison point.
- **Models:** served from `serve.py` on an Apple M4 Max GPU (mps, float16), each pinned in
  `candidates.json`.
  - Qwen3-Embedding-8B is truncated to 2,048 dimensions (Matryoshka).
  - The reranker is bge-reranker-v2-m3.
- **Vectors:** one window per unit at most 2,000 characters, bfloat16 in Vespa, HNSW. Every
  generation validated: no missing units, recompute cosine ≥ 0.99999, approximate recall@20 ≥ 0.995.
- **Engine lexical profile:** BM25 per field with b = 0.3 for words and headings (see the next
  section).

## Engine lexical ranking

Variants through the whole pack, lexical arms only:

| Profile | NDPA nDCG@10 | NDPA MRR | Synthetic nDCG@10 |
|---|---|---|---|
| Before the matching rule (any word, stopwords included) | 0.538 | 0.451 | 0.723 |
| BM25, b = 0.75 (default) | 0.746 | 0.739 | 0.926 |
| **BM25, b = 0.3 for words and headings (adopted)** | **0.783** | **0.786** | **0.921** |
| b = 0.3 plus fieldMatch proximity | 0.769 | 0.772 | 0.921 |

b = 0.3 is adopted over nativeRank for two reasons. It is BM25 with one documented parameter, and
OpenSearch has the same, so the engine stays replaceable. It was chosen on the development set and
is not a held-out result.

### Paired gate against PostgreSQL lexical

`ng-legislation-dev-1-gate-1`: margin 0.02 on nDCG@10, recall@10 and MRR; 0.05 on complete; 0 on
abstain. Family bootstrap, 23 cases.

- **Every ranking comparison is inconclusive.** The 95% intervals on nDCG@10 are about ±0.04 for the
  hybrids and about ±0.11 with the reranker, wider than the margin. One case moves nDCG@10 by about
  0.04.
- **Every hybrid passes recall@10.** The interval is 0.0 to +0.08: dense search finds one provision
  the lexical arms miss.
- **Every hybrid fails abstention.** Dense search always returns neighbours, so the one unanswerable
  question gets an answer.
- **Qwen3-Embedding-8B against 0.6B:** non-inferior, not better (nDCG@10 +0.005, interval −0.017 to
  +0.029).

## What this shows

1. **Nothing here separates the embedders.** On a 170-unit corpus and 23 cases, all four land within
   one case of each other. With the reranker, all four give the same ranking. Choosing a model (D29)
   needs a larger reviewed set: several hundred cases over several laws and judgments, in English
   and French, with unanswerable and adversarial cases.
2. **The reranker carries the quality; the embedder adds recall.** Every reranked configuration
   reaches nDCG@10 0.83, whichever arms fed it.
3. **The hybrid needs an abstention rule before it can serve.** The candidates are a closeness floor
   per profile, or a reranker score floor. One unanswerable case cannot set either.
4. **The reranker undoes some of the dense recall.** It reads only the first 2,000 characters of each
   candidate. A long section whose matching passage comes later scores low and drops out of the top
   10 (recall@10 0.913 to 0.899). Reranking the matched window instead of the opening is the fix to
   try next.
5. **Engine parity.** The Vespa lexical arms trail PostgreSQL's alone (0.783 against 0.810,
   inconclusive) and match them once reranked (0.829 against 0.827). Recall@10 still trails
   (0.848 against 0.891), from units the engine's analysis does not match.

## After the choice of Qwen3-Embedding-0.6B and bge-reranker-v2-m3 (same day)

Two changes to the pack, measured on the same sets:

- **Passage scoring.** A long unit is reranked by its best passage. Its opening and the two windows
  with most of the query's words are scored, and the unit takes the highest. The reranker had read
  only each unit's first 2,000 characters.
- **Support floor.** A weak match, found only by meaning or by some of the query's words, is evidence
  only when the reranker scores it at least 0.1. When the reranker ran, an unscored weak match is
  not evidence. Without a reranker, a meaning-only unit counts only when the query's words found
  something too. Units found by every word, a citation or a definition are never held to the floor.

The floor was set from the scores the reranker gave the units each case received:

| Units | Count | Scores |
|---|---|---|
| Found only by meaning | 130 | none relevant |
| Weak matches for the unanswerable questions | | at most 0.001 |
| Lowest relevant weak match | | 0.259 |
| A relevant citation hit | | 0.0 (hence citations are exempt) |

It is provisional until the larger reviewed benchmark exists.

## End to end through the public service (same day)

The chosen stack ran in a local public service (`api.service`), with REST `/api/v1/retrieve` and the
MCP tool `retrieve_evidence` called with a test key, on the same corpus:
- engine: Vespa;
- vectors: an activated Qwen3-Embedding-0.6B generation;
- reranker: bge-reranker-v2-m3.

| | |
|---|---|
| Revisions in every pack | `vespa`, `qwen3-embedding-0.6b@gen_…`, `BAAI/bge-reranker-v2-m3@953dc6f6f85a`; nothing degraded |
| NDPA development set over HTTP | recall@10 0.913, nDCG@10 0.833, MRR 0.824, complete 0.913, abstain 1.0 (as in process) |
| Synthetic set over HTTP | recall@10 1.0, nDCG@10 0.949, abstain 1.0 |
| Latency, 33 requests, one client | p50 1.33 s, p95 1.70 s, max 1.85 s |
| Where the time goes (M4 Max GPU) | query embedding 0.02 s; Vespa 0.003 s; reranking 50 full 2,000-character passages 2.1 s |

- **A question in other words.** "Can a company send customer data to another country" shares no
  key word with the Act's transfer provision, and still finds s. 41 first, by REST and by MCP.
- **A cited provision.** It came first, but meaning-only units followed it. The reranker scored the
  document unit and two tables 0.98–0.99, because each shares the Act's title with the citation.
  Like the any-word arm, the dense arm no longer runs when a citation resolves.
- **Latency.** The laptop timing is not a service figure. The reranker dominates and will be measured
  on the inference hardware D29 chooses.
